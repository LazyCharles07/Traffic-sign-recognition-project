# 交通路标两阶段识别

上传一张任意尺寸的街景图，返回每个路标的位置和中文含义，并在原图上画出检测框。

检测和分类是两个单独训练的模型。YOLOv8 只负责出框，框上的类别不用它自己的类别号。手写 ResNet-18 只看裁下来的路标小图，给出代码和中文含义。

## 流程

```text
原图
  → YOLOv8 出框和检测置信度
  → 丢掉低于 0.10 的框
  → 重叠达到 0.50 的框只留检测分更高的一个
  → 从原图裁剪，每边按框宽、框高外扩 10%
  → 只对小图做 Resize(224) + ToTensor + ImageNet Normalize
  → ResNet-18 给出类别和分类置信度
  → 在原图上画原来的检测框，标出含义和分类置信度
```

类别来自 Kaggle 数据集 [braunge/tt100k](https://www.kaggle.com/datasets/braunge/tt100k)。保留训练集实例不少于 100 的类，这一版是 50 类，编号 0 到 49，名单在 `weights/dataset.yaml`。画面上画的框仍是检测框，外扩只用于分类。

上传的图片不会写到磁盘。服务只监听 `127.0.0.1`。

## 本地运行

当前 `weights/best.pt` 是按输入边长 960 训练的，启动时要带上 `--imgsz 960`。`weights/best_model.pth` 是分类器，不要换成检测权重。

```bash
pip install -r requirements.txt
py -3.13 demo.py --imgsz 960
```

浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000) 。本机是 CPU 时，一张图大约要几十秒。

## 训练

训练在 Kaggle 上做，加速器是 GPU T4 x2。详细点击步骤见 `操作手册.md` 和 `操作手册-YOLO后台训练.md`。


| 笔记本                               | 作用                                      |
| --------------------------------- | --------------------------------------- |
| `kaggle/tt100k_two_stage.ipynb`   | 筛类、裁剪、训练并评估 ResNet-18，也可训练 640 的 YOLOv8 |
| `kaggle/tt100k_yolo_train.ipynb`  | 只训练检测器，640，30 轮                         |
| `kaggle/tt100k_yolo_960.ipynb`    | 只训练检测器，960，26 轮。当前 `best.pt` 来自这一版      |
| `kaggle/tt100k_yolo_960_22.ipynb` | 只训练检测器，960，22 轮                         |


分类器不再重训。检测器从 `yolov8s.pt` 训练，关闭左右翻转。ResNet-18 含 BasicBlock；通道或步长变化时，捷径用 1×1 卷积。两块 GPU 时分类器用 `DataParallel`，检测器交给 Ultralytics 自己的 DDP，不再套一层 `DataParallel`。

## 实验结果

分类在按类别划分的裁剪测试集上评估，检测在官方验证集上评估（3598 张图，10823 个框）。检测指标是融合 `best.pt` 之后再验的结果。

**ResNet-18：**

20 轮，batch 128，AdamW，混合精度，T4x2。参数量 11,202,162。最优是第 14 轮，验证准确率 0.9980。测试准确率 0.9976（7074/7091），17 个错误。裁剪来自紧的标注框，所以这个数字高于整张街景图上的端到端效果。

**YOLOv8：**


| 训练       | 时间      | 精度    | 召回    | mAP50 | mAP50-95 |
| -------- | ------- | ----- | ----- | ----- | -------- |
| 640，30 轮 | 4.99 小时 | 0.891 | 0.713 | 0.835 | 0.684    |
| 960，22 轮 | 4.85 小时 | 0.942 | 0.854 | 0.941 | 0.795    |
| 960，26 轮 | 5.89 小时 | 0.941 | 0.865 | 0.944 | 0.800    |


26 轮这一版的最后五轮已经走平：召回停在 0.863 到 0.867，mAP50-95 从第 23 轮起是 0.808。训练损失还在降，验证集的框质量不再涨。当前本地检测权重用的是这一版。

相对 640，原先偏弱的类有提升：限速40召回 0.606 → 0.844，禁止二轮摩托车召回 0.567 → 0.760，禁止掉头召回 0.652 → 0.772。

**七张街景测试图。** 验证集变好之后，用 960 权重再测了一遍。标志在画面里不大时，结果稳定或更好：月亮图的限速40和禁止停车、东营立柱上的三块牌子都正确；杭州龙门架上的限速50、禁止停车、机动车行驶、非机动车行驶检测分高于 640 那一版。

近景里牌子占画面很大时，检测仍然不稳。深圳的限速40没有框，施工三角的检测分只有 0.29。北京禁摩只框住圆牌右半，含义错成禁止鸣喇叭。景山后街的禁止掉头没有框，禁止停车只剩右半边，检测分 0.10。同里的「停」字牌框是对的，含义仍是禁止向右转弯：训练集里的禁止停车是蓝底红叉，和这个「停」字牌不是同一种画法。

原因是训练集里的标志大多是街景中的小目标，马赛克还会把它们缩得更小。输入边长 960 能表达这些大框，模型只是很少见过这种尺度。
