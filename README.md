# 交通路标识别

上传一张任意尺寸的街景图，返回每个路标的位置和中文含义，并在原图上画出框。

用两个模型，分开训练。YOLOv8 负责在整张图里找框。ResNet-18 只看裁下来的小图，判断这是哪一种标志、中文是什么。页面上的含义来自 ResNet-18，不用 YOLOv8 自己报的类别。

## 流程

1. 整张原图交给 YOLOv8，得到框，以及它对这个框有多大把握。把握最高是 1。
2. 把握低于 0.10 的框丢掉。
3. 两个框叠在一起，重叠部分达到二者合起来范围的一半时，只留把握更高的那个。
4. 按框从原图裁出小图。裁的时候四边各向外多留约 10%，以免边缘被切掉。画回原图的仍是原来的框。
5. 小图缩放到 224×224，送进 ResNet-18，得到类别和分类把握。
6. 在原图上画出框，标上中文含义和分类把握。

类别来自 Kaggle 上的 [TT100K](https://www.kaggle.com/datasets/braunge/tt100k)。只保留训练集里至少出现 100 次的类别。这一版是 50 类，编号 0 到 49，名单在 `weights/dataset.yaml`。

上传的图片不会存到硬盘。网页只在本机打开，地址是 `127.0.0.1`，同一局域网里的别人打不开。

## 本地运行

`weights/best.pt` 是训练好的检测模型，按边长 960 训练的。启动时加上 `--imgsz 960`，表示送给检测器的图片边长。`weights/best_model.pth` 是训练好的分类模型，不要用检测文件把它盖掉。

```bash
pip install -r requirements.txt
py -3.13 demo.py --imgsz 960
```

浏览器打开 [http://127.0.0.1:8000](http://127.0.0.1:8000)。电脑没有可用的显卡时，一张图大约要几十秒。

## 训练

在 Kaggle 上训练，显卡选两块 T4。具体点哪里、怎么保存版本，看 `操作手册.md` 和 `操作手册-YOLO后台训练.md`。


| 笔记本                               | 作用                                     |
| --------------------------------- | -------------------------------------- |
| `kaggle/tt100k_two_stage.ipynb`   | 筛选类别、裁小图、训练并测试分类器，也可以训练边长 640 的检测器     |
| `kaggle/tt100k_yolo_train.ipynb`  | 只训练检测器，边长 640，30 轮                     |
| `kaggle/tt100k_yolo_960.ipynb`    | 只训练检测器，边长 960，26 轮。现在的 `best.pt` 来自这一版 |
| `kaggle/tt100k_yolo_960_22.ipynb` | 只训练检测器，边长 960，22 轮                     |


分类器已经训完，不要再训。检测器每次都从官方提供的小型 YOLOv8 开始，文件名是 `yolov8s.pt`。训练时不把图片左右翻转，因为不少标志翻过去就变成另一种，比如左转和右转。

## 实验结果

分类看的是裁下来的小图。这些小图按类别分成三份：训练用来学习，验证用来挑选最好的一轮，测试留到最后、不参与挑选。检测看的是数据集自带的验证集，共 3598 张图、10823 个框。

下面四个数的意思是：

- 精度：找出来的框里，有多少确实框住了标志。
- 召回：应该找到的标志里，实际找到了多少。
- mAP50：框和真实位置至少重叠一半就算对，再把各类合成一个分。
- mAP50-95：重叠要求从一半一直收到 95%，更严，所以分数更低。

### 分类器 ResNet-18

训练 20 轮，每次放进 128 张小图，用两块 T4。模型里大约有 1120 万个要学习的数。最好的是第 14 轮，验证准确率 0.9980。测试准确率 0.9976，7091 张里对了 7074 张，错了 17 张。这些小图是按标注紧紧裁出来的，所以这个准确率比拿整张街景去测要高。

### 检测器 YOLOv8

表里的数是训练结束、模型存成文件之后再测的。训练过程中最后一轮的 mAP50-95 是 0.808，存成文件后再测是 0.800，会略低一点。


| 训练          | 时间      | 精度    | 召回    | mAP50 | mAP50-95 |
| ----------- | ------- | ----- | ----- | ----- | -------- |
| 边长 640，30 轮 | 4.99 小时 | 0.891 | 0.713 | 0.835 | 0.684    |
| 边长 960，22 轮 | 4.85 小时 | 0.942 | 0.854 | 0.941 | 0.795    |
| 边长 960，26 轮 | 5.89 小时 | 0.941 | 0.865 | 0.944 | 0.800    |


26 轮这一版的最后五轮已经停住了。召回在 0.863 到 0.867 之间，mAP50-95 从第 23 轮起就是 0.808。训练时的误差还在变小，验证集上的框没有更准。现在本地用的就是这一版。

和边长 640 那一版比，几类原先容易漏掉的标志，召回提高了：

- 限速 40：0.606 → 0.844
- 禁止二轮摩托车：0.567 → 0.760
- 禁止掉头：0.652 → 0.772

### 七张街景测试图

验证集变好之后，用边长 960 的权重又测了一遍。

标志在画面里不大时，结果稳定，或者更好。

- 月亮：限速 40 和禁止停车都对。
- 东营：立柱上的三块牌子都对。
- 杭州：龙门架上的限速 50、禁止停车、机动车行驶、非机动车行驶，把握比边长 640 那一版更高。

牌子在画面里占得很大时，检测仍然不稳。

- 深圳：限速 40 没有框。上面的施工三角框对了，把握只有 0.29。
- 北京禁摩：只框住圆牌的右半边，含义错成了禁止鸣喇叭。
- 景山后街：禁止掉头没有框。禁止停车只剩右半边，把握 0.10。
- 同里：「停」字牌的框是对的，含义仍是禁止向右转弯。训练集里的禁止停车是蓝底红叉，和这个「停」字牌不是同一种画法。

训练集里的照片大多是腾讯街景，标志在画面里很小。训练时还会把四张图拼成一张，标志被缩得更小。所以模型很少见过一块牌子占满画面的照片。边长改成 960 之后，这种大框算得出来，只是训练时几乎没见过。
